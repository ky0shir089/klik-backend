# Plan: Track unit_byad_amount and unit_fee_amount in RvClassificationController store function

## Goal
Track `byad_amount` (0.6% of price) and `fee_amount` (admin fee portion) per unit in the store function.

## Current State
- Unit model already has `byad_amount` and `fee_amount` fields in fillable
- Store function currently calculates byad/fee at RV level only:
  - `$titipanByad = round($rv->used_balance * 0.006)` (0.6%)
  - `$titipanFeeAdmin = $rv->admin_fee - $titipanByad`

## Implementation

### Step 1: Calculate and track per-unit values in the unit loop

Inside the `foreach ($units as $unit)` loop (around line 243-288), after calculating `priceToUse` and `adminFeeToUse`:

```php
// Track byad and fee amounts per unit
$unitByadAmount = round($priceToUse * 0.006);  // 0.6% of price covered by RV
$unitFeeAmount = $adminFeeToUse - $unitByadAmount;  // admin fee minus byad
```

### Step 2: Store values on Unit model

After saving the unit (after line 287), add:

```php
$unit->byad_amount = $unitByadAmount;
$unit->fee_amount = $unitFeeAmount;
$unit->save();
```

### Step 3: Add to RvClassification (optional - if needed)

If you want to also store these in the rv_classifications table, add to the fillable array in RvClassification model first, then:

```php
"byad_amount" => $unitByadAmount,
"fee_amount" => $unitFeeAmount,
```

## Note
The current `$titipanByad` calculation at RV level (line 313) will still work - it's the aggregate of all unit byad amounts. This change just adds per-unit tracking.
